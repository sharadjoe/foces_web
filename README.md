# foces_web

This repository contains the legacy source code for the 2017 FOCES website (`foces.org`).

The official FOCES website has now migrated to:
👉 **[https://foces.ceconline.edu/](https://foces.ceconline.edu/)**

All pages in this repository have been updated with automatic redirects to the new domain, along with an `.htaccess` 301 redirect configuration for Apache / LiteSpeed web servers.
